## 🏗️ Architecture

Zenith is built on the **[base46](https://github.com/NvChad/base46)** architecture — a universal color theming system that ensures consistency across editors, terminals, and development tools.

### Base46 Color System

- 🎨 **16 semantic base colors** that define the core palette
- 🔤 **30 ANSI color mappings** for terminal integration
- 🎯 **Standardized color roles** (base00-base0F) for consistent theming
- 🌐 **Cross-platform compatibility** - same colors everywhere
- 🔧 **Easy customization** through base46 color definitions

### Key Features

- ✨ **Eight unique variants** each with distinct personality
- 🎨 **Soft pastel palettes** designed for long coding sessions
- 💎 **Enhanced syntax highlighting** with semantic token support
- 🖼️ **Refined UI elements** with subtle transparency and borders
- 🔄 **Synced with main Zenith repo** for consistency across platforms
- 📐 **Professional color theory** applied to all variants

## 📦 Installation

**Marketplace**: Search `Zenith Theme` in VS Code extensions

**Manual**: Press `Ctrl+Shift+P` → `Install from VSIX` → Select `.vsix` file

**Activate**: Press `Ctrl+K Ctrl+T` → Choose your variant

## ⚙️ Recommended Settings

```json
{
  "editor.fontFamily": "'JetBrains Mono', 'Fira Code', 'Cascadia Code'",
  "editor.fontLigatures": true,
  "editor.semanticHighlighting.enabled": true
}
```
